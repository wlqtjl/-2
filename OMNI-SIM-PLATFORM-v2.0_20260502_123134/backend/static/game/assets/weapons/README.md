# 武器 GLB 资产目录

将武器 GLB 文件放到此目录。WeaponViewmodel.loadAsync('/assets/weapons/smg.glb') 会优先加载。

## 获取 smg.glb
1. 浏览器打开 http://localhost:5173/bake-weapon.html
2. 点击 'Bake & Download smg.glb' 
3. 将下载文件放到此目录

## 更高质量资产（可选，CC0 许可）
- Quaternius: https://quaternius.com/packs/ultimateguns.html
- Kenney Blaster Kit: https://kenney.nl/assets/blaster-kit
- Sketchfab (CC0 filter): https://sketchfab.com/3d-models?features=downloadable&license=0
