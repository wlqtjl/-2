📦 安装包文件列表
================

✅ 安装脚本
├── install.sh                      # macOS/Linux 安装脚本
├── install.bat                     # Windows 安装脚本
├── start.sh                        # macOS/Linux 启动脚本
└── start.bat                       # Windows 启动脚本

✅ 项目文档
├── README.md                       # 项目说明文档
├── INSTALL.md                      # 安装包说明文档
└── .gitignore                      # Git忽略文件

✅ 后端服务
├── backend/
│   ├── requirements.txt            # Python依赖
│   ├── main.py                     # FastAPI应用入口
│   ├── game_training.db            # SQLite数据库（含示例数据）
│   ├── .env.example                # 环境变量示例
│   └── apps/
│       ├── ai/                    # AI模块（文档解析、题目生成）
│       ├── api/                   # API路由
│       └── core/                  # 核心模块（数据库、认证）

✅ 前端应用
└── frontend/
    └── apps/web/
        ├── package.json            # Node依赖
        ├── src/
        │   ├── components/         # React组件
        │   ├── pages/             # 页面组件
        │   └── api/               # API客户端
        └── vite.config.ts          # Vite配置


🚀 快速开始
===========

macOS/Linux:
  chmod +x install.sh
  ./install.sh
  ./start.sh

Windows:
  install.bat
  start.bat


📋 访问地址
===========
前端: http://localhost:3002
后端: http://localhost:8000
API文档: http://localhost:8000/docs
